# happy-birthday

Onepage “site mystérieux”:
- Au démarrage: bouton **“Clique sur moi”**
- Après clic: compte à rebours **10 → 0**
- À zéro: **“JOYEUX ANNIVERSAIRE / PAPA”** + confetti

## Confetti
- Le projet inclut un confetti **sans dépendance** (`src/lib/confetti.js`).
- Si tu préfères un package npm: **`canvas-confetti`**.
